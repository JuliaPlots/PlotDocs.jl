Ribbons

using Plots
pythonplot()

Ribbons can be added to lines via the ribbon keyword; you can pass a tuple of arrays (lower and upper bounds, in this order), a single Array (for symmetric ribbons), a Function, or a number.

plot(plot(0:10; ribbon = (LinRange(0, 2, 11), LinRange(0, 1, 11))), plot(0:10; ribbon = 0:0.5:5), plot(0:10; ribbon = sqrt), plot(0:10; ribbon = 1))
