Legend columns

using Plots
pgfplotsx()

legend_column sets the number of columns in the legend, which are filled row by row. -1 puts every entry in one row.

plot((plot(rand(5, 5); label = ["a" "b" "c" "d" "e"], legend_column = c, title = "legend_column = $(c)") for c = (1, 2, 3, -1))...; layout = 4, size = (1000, 700))
